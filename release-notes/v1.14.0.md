## Download

[**RansomGuard.exe**](https://github.com/leo-code-del/RansomGuard/releases/download/v1.14.0/RansomGuard.exe) (Windows 10 / 11)

**Update:** click **Check for updates** under **Tools** in the control panel (before 1.11.0: on the main window; 1.7.3: **Update to the latest version**).

**Verify the download:** with the [GitHub CLI](https://cli.github.com/) installed, run `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`.

## What's new in 1.14.0 — a quiet clock, exclude busy subfolders

- Nothing shows by the clock any more while all is well, also not while file detection is paused. Only when the network is cut does a shield with a red dot appear there, with a Windows notification; click either for the control panel and the detection report. The setting is now **Show a notice by the clock when the network is cut**
- **Settings** → **Watched folders…** has a new list: subfolders file detection skips. Use it for folders that change a lot on their own, such as `node_modules` or a build output folder in a watched drive, so they can't cause false alarms
- Only a folder inside a watched one can be excluded, never a whole watched folder. Canary files and dangerous commands are still watched; Defender still scans new downloads
- The list is kept where only administrators can change it, so a program running as you can't hide its work in an excluded folder
- **Self-check** lists the excluded subfolders, so they aren't forgotten

## 1.14.0 更新內容 — 安靜的時鐘、排除會大量變動的子資料夾

**更新方式：** 在控制台的 **工具** 裡按 **檢查版本更新**（1.11.0 以前：在主畫面；1.7.3：**更新到最新版本**）。

**驗證下載的檔案：** 安裝 [GitHub CLI](https://cli.github.com/) 後，執行 `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`。

- 一切正常時（包括暫停檔案偵測時），時鐘旁不再出現任何東西。只有網路被切斷時，才會出現紅點盾牌和 Windows 通知；點任一個都會開啟控制台查看偵測報告。設定改為 **網路被切斷時在時鐘旁顯示提示**
- **設定** → **監控的資料夾…** 新增一個清單：不偵測的子資料夾。用在會自己大量變動的資料夾，例如監控的磁碟裡的 `node_modules` 或程式的輸出資料夾，避免它們造成誤判
- 只能排除監控的資料夾裡面的子資料夾，不能排除整個監控的資料夾。誘餌檔和危險指令照常監控；Defender 照常掃描新下載的檔案
- 清單存在只有系統管理員能修改的地方，以你的身分執行的程式無法把自己藏進排除的資料夾
- **自我檢查** 會列出排除的子資料夾，避免忘記
