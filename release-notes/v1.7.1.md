## Download

[**RansomGuard.exe**](https://github.com/leo-code-del/RansomGuard/releases/download/v1.7.1/RansomGuard.exe) (Windows 10 / 11)

**Update:** RansomGuard 1.5.0 and later ask you to update by themselves, or click **Install / update and start monitoring** in the control panel (from this version on: **Update to the latest version**).

**Verify the download:** this exe was built by GitHub Actions from the tagged source code. With the [GitHub CLI](https://cli.github.com/) installed, run `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`.

## What's new in 1.7.1

- The control panel has two buttons instead of one: **Install and start monitoring** keeps the version you have and doesn't contact GitHub, **Update to the latest version** updates. When a newer version is out, the update button names it and turns blue. You can stay on the version you have and update whenever you like
- Releases are now built and published by GitHub Actions, with a signed build provenance attestation you can verify (see above), and each release is immutable once published
- The README describes everything RansomGuard does to your computer, how it is developed, and its known limitations and risks
- More automated tests; the whole test suite is now prevented from touching your files, network settings or the internet
