## Download

[**RansomGuard.exe**](https://github.com/leo-code-del/RansomGuard/releases/download/v1.7.2/RansomGuard.exe) (Windows 10 / 11)

**Update:** RansomGuard 1.5.0 to 1.7.0 ask you to update by themselves, or click **Install / update and start monitoring** in the control panel.

**If you installed 1.7.1:** it doesn't start, so neither the control panel nor the background monitor runs. Download RansomGuard.exe above, run it and click **Install and start monitoring**.

**Verify the download:** with the [GitHub CLI](https://cli.github.com/) installed, run `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`.

## What's new in 1.7.2

- Fixed: 1.7.1 stopped right after starting ("Tcl data directory ... not found"), so the control panel didn't open and background monitoring didn't run. It had been built with a newer Python whose Tcl/Tk files weren't packed into the exe. Releases are now built with exactly the Python version that was tested, and every build checks that these files are packed before it can be released
- Everything new in 1.7.1: separate **Install and start monitoring** and **Update to the latest version** buttons, releases built by GitHub Actions with a verifiable attestation, and a README describing what RansomGuard does, how it is developed and its limits
