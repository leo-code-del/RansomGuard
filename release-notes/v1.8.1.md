## Download

[**RansomGuard.exe**](https://github.com/leo-code-del/RansomGuard/releases/download/v1.8.1/RansomGuard.exe) (Windows 10 / 11)

**Update:** click **Check for updates** in the control panel (1.7.3: **Update to the latest version**).

**Verify the download:** with the [GitHub CLI](https://cli.github.com/) installed, run `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`.

## What's new in 1.8.1 — detection report

When RansomGuard cuts the network, it now tells you why, so you can tell a false alarm from a real attack:

- The full-screen warning names a few of the files that looked encrypted
- While the network is cut, the control panel shows the detection report: why it triggered, which files looked encrypted (up to 50), which programs were paused
- **Restore network and restart monitoring** shows the report before it asks, and the reminder after a restart names the reason
- The report is kept in `C:\ProgramData\RansomGuard\state.json` (only administrators can change it) until you restore the network

## 1.8.1 更新內容 — 偵測報告

**更新方式：** 在控制台按 **檢查版本更新**（1.7.3：**更新到最新版本**）。

**驗證下載的檔案：** 安裝 [GitHub CLI](https://cli.github.com/) 後，執行 `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`。

RansomGuard 切斷網路時，現在會告訴你原因，方便你判斷是誤判還是真的中毒：

- 全螢幕警告會列出幾個被判定像被加密的檔案
- 網路被切斷期間，控制台會顯示偵測報告：為什麼觸發、哪些檔案被判定像被加密（最多 50 個）、暫停了哪些程式
- 按 **恢復網路並重新開啟監控** 時，確認視窗會先列出報告；重新開機後的提醒也會寫出原因
- 報告存在 `C:\ProgramData\RansomGuard\state.json`（只有系統管理員能修改），恢復網路後清除
