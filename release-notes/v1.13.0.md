## Download

[**RansomGuard.exe**](https://github.com/leo-code-del/RansomGuard/releases/download/v1.13.0/RansomGuard.exe) (Windows 10 / 11)

**Update:** click **Check for updates** under **Tools** in the control panel (before 1.11.0: on the main window; 1.7.3: **Update to the latest version**).

**Verify the download:** with the [GitHub CLI](https://cli.github.com/) installed, run `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`.

## What's new in 1.13.0 — an icon by the clock

- The background monitor shows a shield in the notification area: a **green** dot means protected, **orange** file detection paused, **red** the network cut. It never blinks
- Rest the mouse on it for the state in words; click it for the control panel; right-click it to pause file detection for 30 minutes or resume it
- The monitor shows it itself, so no icon means monitoring isn't running
- Turn it off under **Settings** → **Show an icon in the notification area**

## 1.13.0 更新內容 — 時鐘旁的圖示

**更新方式：** 在控制台的 **工具** 裡按 **檢查版本更新**（1.11.0 以前：在主畫面；1.7.3：**更新到最新版本**）。

**驗證下載的檔案：** 安裝 [GitHub CLI](https://cli.github.com/) 後，執行 `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`。

- 背景監控會在工作列時鐘旁的通知區域顯示盾牌圖示：**綠點**已受到保護、**橘點**檔案偵測暫停中、**紅點**網路已切斷，不會閃爍
- 滑鼠停在上面會用文字說明狀態；點它開啟控制台；按右鍵可以暫停檔案偵測 30 分鐘或恢復偵測
- 圖示由背景監控自己顯示，所以圖示不見了，表示監控沒在執行
- 可以在 **設定** → **在通知區域顯示圖示** 關閉
