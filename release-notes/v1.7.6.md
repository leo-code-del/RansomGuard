## Download

[**RansomGuard.exe**](https://github.com/leo-code-del/RansomGuard/releases/download/v1.7.6/RansomGuard.exe) (Windows 10 / 11)

**Update:** click **Check for updates** in the control panel (1.7.3: **Update to the latest version**).

**Verify the download:** with the [GitHub CLI](https://cli.github.com/) installed, run `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`.

## What's new in 1.7.6

- After a trigger, monitoring keeps working while the warning is open. If the trigger was a dangerous command, another one is now stopped too
- A watched USB drive or NAS that is unplugged and connected again is watched again within a minute, and so is one that wasn't connected when you signed in. One connected for the first time gets its canary files first
- Code tidied up after splitting the program into modules

## 1.7.6 更新內容

**更新方式：** 在控制台按 **檢查版本更新**（1.7.3：**更新到最新版本**）。

**驗證下載的檔案：** 安裝 [GitHub CLI](https://cli.github.com/) 後，執行 `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`。

- 觸發之後，警告畫面開著的期間監控會繼續運作。如果是危險指令觸發的，之後再出現的危險指令也會被攔截
- 監控中的隨身碟或 NAS 拔掉再接上，一分鐘內會重新開始監控；登入時沒有接上的也一樣。第一次接上的會先放好誘餌檔
- 拆成模組之後的程式碼整理
