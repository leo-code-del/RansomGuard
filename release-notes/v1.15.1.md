## Download

[**RansomGuard.exe**](https://github.com/leo-code-del/RansomGuard/releases/download/v1.15.1/RansomGuard.exe) (Windows 10 / 11)

**Update:** click **Check for updates** under **Tools** in the control panel (before 1.11.0: on the main window; 1.7.3: **Update to the latest version**).

**Verify the download:** with the [GitHub CLI](https://cli.github.com/) installed, run `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`.

## What's new in 1.15.1

- **Restoring the network works for every adapter name.** A name with a typographic apostrophe (such as "Kevin’s iPhone") broke the whole restore command, and a name with brackets (such as "Ethernet [USB]") wasn't found, so that adapter stayed off. Adapters are now matched by their exact name, so restoring also never turns on one that RansomGuard didn't turn off
- **A cut network always shows as cut.** If PowerShell couldn't start at all, the network was still cut, but the control panel said it was normal and restoring didn't get a new address
- The time of the detection stays the same when the network is cut again because an adapter came back on while the warning was open
- The process monitor no longer leaves an open pipe and process handle behind each time it is restarted
- A program paused for starting a destructive command always shows in the warning
- Unpacking thousands of code files (such as `npm install`) costs less CPU: the file check skipped up to 4 seconds of extra work for 10,000 files

## 1.15.1 更新內容

**更新方式：** 在控制台的 **工具** 裡按 **檢查版本更新**（1.11.0 以前：在主畫面；1.7.3：**更新到最新版本**）。

**驗證下載的檔案：** 安裝 [GitHub CLI](https://cli.github.com/) 後，執行 `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`。

- **不管網路卡叫什麼名字，都能恢復網路。** 以前名稱含有彎引號（例如「Kevin’s iPhone」）時，整個恢復指令會失敗；名稱含有方括號（例如「Ethernet [USB]」）時找不到那張網路卡，它就一直停用。現在改成完全比對名稱，恢復網路時也不會開啟不是 RansomGuard 停用的網路卡
- **網路被切斷時一定會顯示已切斷。** 以前如果 PowerShell 完全無法啟動，網路還是會被切斷，但控制台會顯示正常，恢復網路時也不會重新取得 IP 位址
- 警告畫面開著時，如果有網路卡被重新啟用而再次切斷網路，偵測時間不會再被改掉
- 程序監控每次重新啟動，不會再留下沒關閉的管線和程序控制代碼
- 因為下達危險指令而被暫停的程式，一定會顯示在警告畫面上
- 解壓縮大量程式碼檔案（例如 `npm install`）時更省 CPU：一萬個檔案最多省下約 4 秒的多餘運算
