## Download

[**RansomGuard.exe**](https://github.com/leo-code-del/RansomGuard/releases/download/v1.12.0/RansomGuard.exe) (Windows 10 / 11)

**Update:** click **Check for updates** under **Tools** in the control panel (before 1.11.0: on the main window; 1.7.3: **Update to the latest version**).

**Verify the download:** with the [GitHub CLI](https://cli.github.com/) installed, run `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`.

## What's new in 1.12.0 — back within a minute

- If something ends the background monitor, Windows starts it again **within a minute** instead of five. Ransomware with administrator rights often ends security programs first; this shortens the time without protection
- While you have stopped monitoring until restart, the program is no longer started every few minutes just to exit again (each start unpacked it, about 12 MB). Monitoring puts the every-minute start back when it runs again
- An existing install switches to one minute by itself when the updated monitor starts; no need to install again
- **Self-check** also reports how soon monitoring would start again if it were ended

## 1.12.0 更新內容 — 一分鐘內重新啟動

**更新方式：** 在控制台的 **工具** 裡按 **檢查版本更新**（1.11.0 以前：在主畫面；1.7.3：**更新到最新版本**）。

**驗證下載的檔案：** 安裝 [GitHub CLI](https://cli.github.com/) 後，執行 `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`。

- 背景監控被結束時，Windows 會在 **1 分鐘內** 重新啟動它（原本是 5 分鐘）。取得系統管理員權限的勒索病毒常會先關掉防護軟體，這縮短了沒有防護的時間
- 你停止監控到重新開機的期間，程式不會再每隔幾分鐘被啟動一次、又馬上結束（每次都要解壓約 12 MB）。監控再次執行時，會自動把每分鐘重新啟動的設定加回來
- 已安裝的版本在更新後的監控啟動時，會自動改成 1 分鐘，不需要重新安裝
- **自我檢查** 也會顯示監控被結束時多快會重新啟動
