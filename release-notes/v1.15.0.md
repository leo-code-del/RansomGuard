## What's new in 1.15.0 — the right program paused, sooner

- **The program that encrypts is the one paused.** RansomGuard now follows Windows' kernel file events to know which program wrote which file in the watched folders. On a trigger it pauses the programs that wrote the files that looked encrypted, instead of the ones writing the most data, which were often busy editors or browsers. In 20 trials with a stand-in encryptor next to a program writing 2 MB a second, the encryptor was found every time and the busy program never, about 0.3 seconds after the trigger. If the events name nobody, it pauses the programs writing the most, as before
- **Ransomware that never pauses is caught while it works.** File changes used to reach detection only after a quiet second in the watched folders, so a program writing all the time, such as ransomware encrypting file after file, was noticed only when it stopped. They now arrive at once: a stand-in encrypting 200 files was caught at the 9th
- **The network is cut sooner**: at the same time as pausing, with one PowerShell instead of two
- Reading a file to check it no longer stops another program from renaming or deleting it at that moment (a program saving a file often does that)
- **Self-check** tells whether file write tracing is running
- What the file trace keeps (which program wrote which file, no content) stays in memory for a couple of minutes and is never written down; see the [privacy notice](https://github.com/leo-code-del/RansomGuard/blob/main/PRIVACY.md)

## 1.15.0 更新內容 — 更快、更準地暫停正確的程式

**更新方式：** 在控制台的 **工具** 裡按 **檢查版本更新**（1.11.0 以前：在主畫面；1.7.3：**更新到最新版本**）。

**驗證下載的檔案：** 安裝 [GitHub CLI](https://cli.github.com/) 後，執行 `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`。

- **被暫停的是真正在加密的程式。** RansomGuard 現在會透過 Windows 核心的檔案事件，記下監控的資料夾裡哪個程式寫了哪個檔案。觸發時，暫停寫入那些被加密檔案的程式，而不是寫入最多資料的程式（以前常常是忙碌的編輯器或瀏覽器）。用模擬的加密程式搭配一個每秒寫入 2 MB 的程式測試 20 次，每次都找到加密程式、一次都沒有找上那個程式，觸發後約 0.3 秒就找到。檔案事件找不到時，和以前一樣暫停寫入最多的程式
- **一直不停加密的勒索病毒，會在加密途中就被抓到。** 以前監控的資料夾要安靜一秒，檔案變動才會送去偵測；一直寫檔的程式（例如一個接一個加密檔案的勒索病毒）要等它停下來才會被注意到。現在變動會立刻送到：模擬加密 200 個檔案的程式，在第 9 個就被抓到
- **更快切斷網路**：和暫停程式同時進行，而且只啟動一次 PowerShell（以前要兩次）
- 檢查檔案時，不會再擋住別的程式在那一刻改名或刪除它（程式存檔時常常這樣做）
- **自我檢查** 會顯示檔案寫入追蹤是否在執行
- 檔案追蹤記下的內容（哪個程式寫了哪個檔案，沒有檔案內容）只在記憶體裡保留幾分鐘，不會寫進檔案；詳見[隱私權說明](https://github.com/leo-code-del/RansomGuard/blob/main/PRIVACY.zh-TW.md)
