**Update:** click **Check for updates** in the control panel (1.7.3: **Update to the latest version**).

**Verify the download:** with the [GitHub CLI](https://cli.github.com/) installed, run `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`.

## What's new in 1.11.0 — pause file detection

- **Stop monitoring** is now **Pause or stop monitoring**. Before bulk work (converting, renaming or encrypting many files on purpose), pause file detection for 30 minutes or 2 hours instead of being cut off by a false alarm
- While paused, files that look encrypted, unknown extensions, ransom notes and encrypted copies aren't counted. Canary files and dangerous commands are still watched
- It applies within a second and resumes by itself; the status card shows until when, and you can resume earlier
- The pause is kept where only administrators can change it, so a program running as you can't pause detection

## 1.11.0 更新內容 — 暫停檔案偵測

**更新方式：** 在控制台按 **檢查版本更新**（1.7.3：**更新到最新版本**）。

**驗證下載的檔案：** 安裝 [GitHub CLI](https://cli.github.com/) 後，執行 `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`。

- **停止監控** 改為 **暫停／停止監控**。要大量轉檔、改名或用加密軟體加密檔案前，可以暫停檔案偵測 30 分鐘或 2 小時，不用再被誤判斷網
- 暫停期間不計算「檔案像被加密」「陌生副檔名」「勒索信」「加密副本」；誘餌檔和危險指令照常監控
- 一秒內生效，時間到自動恢復；狀態卡片會顯示恢復時間，也可以提早恢復
- 暫停設定存在只有系統管理員能修改的地方，以你的身分執行的程式無法自己暫停偵測
