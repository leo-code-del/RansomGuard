## What's new in 1.7.5 — harder to get around

**Security**

- What RansomGuard acts on with administrator rights (network state, canary record, watched folders) now lives in `C:\ProgramData\RansomGuard`, which only administrators can change, and is checked before use. A program running as you can no longer make **Restore network** turn the firewall off. This was listed as a known security issue
- If something ends the background monitor, Windows starts it again within 5 minutes. **Stop monitoring** now holds until you start it again or restart Windows
- After a trigger, monitoring keeps running: it still stops dangerous commands and pauses the programs behind them while the network is cut

**Detection**

- Canary files have ordinary-looking names, so ransomware that skips obvious decoys still reaches them, and they are hidden, so they aren't touched by accident. They are now in every watched folder, not just Documents and Pictures. A file of your own with the same name is never overwritten or deleted
- New **Watched folders…** at the bottom of the control panel: add another drive, a USB drive or a NAS. A watched USB drive being unplugged and plugged in again no longer stops monitoring for good

**Code**

- The program, one 3,300-line file until now, is split into 14 smaller modules, so it is easier to read, review and maintain. It works the same as before

## 1.7.5 更新內容 — 更難被繞過

**更新方式：** 在控制台按 **檢查版本更新**（1.7.3：**更新到最新版本**）。

**驗證下載的檔案：** 安裝 [GitHub CLI](https://cli.github.com/) 後，執行 `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`。

**安全性**

- RansomGuard 以系統管理員權限使用的資料（網路狀態、誘餌檔紀錄、監控的資料夾）移到只有系統管理員能修改的 `C:\ProgramData\RansomGuard`，使用前也會先檢查。以你的身分執行的程式，再也無法讓 **恢復網路** 把防火牆關掉。這原本列在已知的安全問題中
- 背景監控被結束時，Windows 會在 5 分鐘內重新啟動它。**停止監控** 現在會維持到你重新開始監控或重新開機
- 觸發之後監控會繼續執行：斷網期間仍會攔截危險指令、暫停下達指令的程式

**偵測**

- 誘餌檔改用看起來像一般文件的檔名，會刻意跳過明顯誘餌的勒索病毒也會碰到它們；同時設為隱藏檔，避免被誤動。誘餌檔現在放在每個監控的資料夾，不只文件和圖片。你自己同名的檔案絕對不會被覆蓋或刪除
- 控制台下方新增 **監控的資料夾…**：可以加入其他磁碟、隨身碟或 NAS。監控中的隨身碟拔掉再插上，也不會讓監控永久停止

**程式碼**

- 原本 3300 多行的單一檔案拆成 14 個較小的模組，更容易閱讀、審查與維護，功能和之前一樣
