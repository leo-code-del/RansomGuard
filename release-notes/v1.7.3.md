## Download

[**RansomGuard.exe**](https://github.com/leo-code-del/RansomGuard/releases/download/v1.7.3/RansomGuard.exe) (Windows 10 / 11)

**Update:** click **Update to the latest version** in the control panel (1.5.0 to 1.7.0: **Install / update and start monitoring**).

**Verify the download:** with the [GitHub CLI](https://cli.github.com/) installed, run `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`.

## What's new in 1.7.3 — privacy

- **No internet connection unless you want one.** RansomGuard no longer checks GitHub for new versions by itself, because each check shows GitHub your computer's IP address. To be told about new versions, tick **Check for updates automatically** at the bottom left of the control panel (it explains this before turning on). **Update to the latest version** works as before
- The log keeps only the last 30 days, and the new **Clear log** button empties it
- Uninstalling now also deletes RansomGuard's log and settings, so nothing of yours is left behind
- New [privacy page](https://github.com/leo-code-del/RansomGuard/blob/main/PRIVACY.md), following the GDPR's principles: the developer collects nothing, what stays on your computer and for how long, what GitHub and Microsoft Defender see, and how to delete everything

## 1.7.3 更新內容 — 隱私權

**更新方式：** 在控制台按 **更新到最新版本**（1.5.0 到 1.7.0：**安裝／更新並開始監控**）。

**驗證下載的檔案：** 安裝 [GitHub CLI](https://cli.github.com/) 後，執行 `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`。

- **除非你需要，否則不會連上網路。** RansomGuard 不再自己到 GitHub 檢查新版本，因為每次檢查都會讓 GitHub 看到你電腦的 IP 位址。想在有新版本時收到通知，請勾選控制台左下角的 **自動檢查新版本**（開啟前會先說明）。**更新到最新版本** 按鈕照常可以使用
- 紀錄檔只保留最近 30 天，新增的 **清除紀錄檔** 按鈕可以清空它
- 解除安裝時也會刪除 RansomGuard 的紀錄檔和設定，不會留下任何你的資料
- 新增依循 GDPR 原則撰寫的[隱私權說明](https://github.com/leo-code-del/RansomGuard/blob/main/PRIVACY.zh-TW.md)：開發者不收集任何資料、哪些資料留在你的電腦上以及保存多久、GitHub 和 Microsoft Defender 看得到什麼，以及如何刪除所有資料
