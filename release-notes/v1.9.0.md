## What's new in 1.9.0 — backup status

RansomGuard cuts the network when ransomware strikes, but it can't bring encrypted files back. Only a backup can. Now it tells you whether you have one:

- A new **Backup** row in the control panel shows whether File History or OneDrive backs up your files, and when File History last did
- **Backup…** explains how to set one up (File History to an external drive you unplug afterwards, or OneDrive for Desktop, Documents and Pictures) and opens Windows' own settings
- Without an up-to-date backup, the background monitor reminds you with an information box, at most every 14 days. Tick "I back up with another program" to stop the reminders
- Only read: no backup setting is changed and nothing leaves the computer

## 1.9.0 更新內容 — 備份狀態

**更新方式：** 在控制台按 **檢查版本更新**（1.7.3：**更新到最新版本**）。

**驗證下載的檔案：** 安裝 [GitHub CLI](https://cli.github.com/) 後，執行 `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`。

RansomGuard 能在勒索病毒發作時切斷網路，但救不回已經被加密的檔案，只有備份可以。現在它會告訴你有沒有備份：

- 控制台新增 **備份** 一列，顯示檔案有沒有用檔案歷程記錄或 OneDrive 備份，以及檔案歷程記錄上次備份的時間
- **備份…** 會說明設定方式（用檔案歷程記錄備份到外接硬碟、備份完拔掉，或用 OneDrive 備份桌面、文件、圖片），並開啟 Windows 的設定
- 沒有近期的備份時，背景監控會跳出資訊視窗提醒，最多每 14 天一次；勾選「我用其他備份程式」就不再提醒
- 只讀取：不會更改任何備份設定，也不會把資料送出電腦
