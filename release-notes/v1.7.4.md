## Download

[**RansomGuard.exe**](https://github.com/leo-code-del/RansomGuard/releases/download/v1.7.4/RansomGuard.exe) (Windows 10 / 11)

**Update:** click **Update to the latest version** in the control panel (1.5.0 to 1.7.0: **Install / update and start monitoring**). From this version on the button is called **Check for updates**.

**Verify the download:** with the [GitHub CLI](https://cli.github.com/) installed, run `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`.

## What's new in 1.7.4 — a clearer control panel

- **Check for updates** replaces "Update to the latest version": it asks GitHub, tells you whether you have the latest version, and asks before updating
- The buttons are grouped: **Protection** (install and start monitoring, stop monitoring, restore network) and **Tools** (check for updates, preview warning, open log, clear log)
- Only the button you need right now is colored: install when monitoring isn't running, restore while the network is cut, update when a newer version is known
- Rest the mouse on any button to see what it does
- The box showing what a button is doing is now called **Progress**, so it isn't confused with the log file
- Fixed: a long status note could be cut off at the edge of its card

## 1.7.4 更新內容 — 更清楚的控制台

**更新方式：** 在控制台按 **更新到最新版本**（1.5.0 到 1.7.0：**安裝／更新並開始監控**）。從這一版起，這個按鈕改名為 **檢查版本更新**。

**驗證下載的檔案：** 安裝 [GitHub CLI](https://cli.github.com/) 後，執行 `gh attestation verify RansomGuard.exe --repo leo-code-del/RansomGuard`。

- **檢查版本更新** 取代「更新到最新版本」：它會向 GitHub 查詢、告訴你是不是最新版本，更新前也會先詢問
- 按鈕分成兩組：**防護**（安裝並開始監控、停止監控、恢復網路）和 **工具**（檢查版本更新、預覽警告畫面、開啟紀錄檔、清除紀錄檔）
- 只有「現在需要你按」的按鈕會有顏色：監控沒在執行時是安裝、斷網時是恢復網路、有新版本時是更新
- 滑鼠停在任何按鈕上都可以看到說明
- 顯示按鈕執行情況的區塊改名為 **執行進度**，避免和紀錄檔搞混
- 修正：狀態卡片裡較長的說明可能被切掉
